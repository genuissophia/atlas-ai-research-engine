# Atlas — AI Research & Intelligence Engine

An AI-powered research application built from scratch while learning software engineering, system architecture, and AI infrastructure.

## Project Overview

Atlas is a research assistant designed to collect information, organize evidence, and generate structured, source-backed reports.

I'm developing this project incrementally, documenting the technical concepts I learn, the architectural decisions I make, and the challenges I encounter.

**Current status:** Week 1 — Python and API fundamentals

## Technology Stack

- Python
- FastAPI
- GitHub
- Planned: PostgreSQL, React, Docker, and LLM APIs

1. Understand the architecture of modern software applications.
2. Build and deploy a functional AI-powered product.
3. Learn to evaluate performance, reliability, and scalability.
4. Document technical decisions and lessons learned.

## Development Philosophy

AI tools assist with learning, implementation, and debugging. My goal is to understand and independently explain the systems I build, rather than simply generate code.
